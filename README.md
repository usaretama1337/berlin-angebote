# Акции недели в Берлине

Сайт с акциями REWE, EDEKA Riebe и ALDI Nord: товары разложены по группам
(«Напитки и сладкая вода», «Вкусности», «Овощи и фрукты» и т. д.), их можно
фильтровать по магазину, группе, размеру скидки и искать по названию.

## Как это устроено

REWE и EDEKA не пускают сборщик с серверов GitHub (они в США и помечены как
дата-центр). Поэтому акции собирает **ваш компьютер**, а GitHub только
показывает сайт:

1. `run.bat` открывает сайты магазинов в браузере, собирает акции
   и сохраняет их в `site/offers.json`;
2. затем загружает этот файл в ваш репозиторий на GitHub;
3. GitHub сам обновляет сайт через 1–2 минуты.

## Первая настройка (Windows)

1. **Python.** Установите с python.org. В установщике отметьте
   «Add python.exe to PATH».
2. **Программы для сборщика.** Распакуйте архив в удобную папку и
   дважды щёлкните `setup.bat`.
3. **Репозиторий на GitHub.** Создайте репозиторий `berlin-angebote` и
   загрузите в него файлы проекта (Add file → Upload files), сохранив папки.
   Папка `.github` скрытая: включите показ скрытых файлов, чтобы её увидеть.
   Если в репозитории уже есть старая версия, просто замените файлы.
4. **Сайт.** Settings → Pages → Source: **GitHub Actions**.
5. **Токен, чтобы компьютер мог загружать акции.** На GitHub:
   Settings (вашего профиля) → Developer settings → Personal access tokens →
   Fine-grained tokens → Generate new token. Repository access: только
   `berlin-angebote`. Permissions → Contents: **Read and write**.
   Скопируйте токен и сохраните его в файл `github_token.txt` в папке проекта
   на компьютере. **Этот файл не загружайте на GitHub.**
6. **Ваш репозиторий в настройках.** В `scraper/config.py` впишите
   `GITHUB_REPO = "ваш-логин/berlin-angebote"`.
7. **Проверка.** Дважды щёлкните `run.bat`. Откроется окно браузера и само
   пролистает три сайта; это занимает 3–5 минут. В конце должно появиться
   «offers.json загружен на GitHub». Сайт будет по адресу
   `https://ваш-логин.github.io/berlin-angebote/`.

## Автозапуск по расписанию

Планировщик заданий Windows → Создать задачу:

- Триггеры: еженедельно, понедельник и четверг, например в 8:00
  (по четвергам у ALDI Nord выходят новые акции).
- Действия: запуск программы `run.bat` из папки проекта, аргумент `auto`
  (чтобы окно в конце не ждало нажатия клавиши), «Рабочая папка» — папка проекта.
- Параметры: отметьте «Немедленно запускать задачу, если пропущен плановый запуск».

Компьютер в это время должен быть включён, а вы вошли в систему: сборщику
нужно окно браузера. Если компьютер был выключен, задача выполнится, когда
вы его включите.

## macOS и Linux

```
pip3 install -r requirements.txt
python3 -m playwright install chromium
./run.sh
```

Для расписания добавьте `run.sh` в cron или в «Автоматизацию» macOS.

## Если магазин не собрался

Сайт покажет плашку, например «сайт магазина не пустил сборщик», и оставит
прошлые акции этого магазина. Для разбора в папке `debug/` на компьютере
лежат для каждого магазина `screenshot.png`, `page.html` и `summary.json`.

## Настройки

- Магазин EDEKA: поле `url` у EDEKA Riebe в `scraper/config.py`.
- Скрыть окно браузера: `HEADLESS = True` в `scraper/config.py`.
  Если после этого REWE или EDEKA перестанут собираться, верните `False`.
- Группы товаров: ключевые слова в `scraper/categories.py`. Товар попадает
  в первую подходящую группу сверху.
