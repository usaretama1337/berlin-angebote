# Акции недели в Берлине

Сайт, который сам собирает акции REWE, EDEKA Riebe и ALDI Nord, раскладывает товары
по группам («Напитки и сладкая вода», «Вкусности», «Овощи и фрукты» и т. д.)
и даёт их фильтровать по магазину, группе, размеру скидки и поиску.

Сборщик запускается на GitHub сам по понедельникам и четвергам. Сайт
бесплатно живёт на GitHub Pages и открывается с телефона.

## Запуск (один раз, около 10 минут)

1. Создайте на github.com новый репозиторий, например `berlin-angebote`
   (можно публичный, так GitHub Actions бесплатны без ограничений).
2. Загрузите в него все файлы из архива, сохранив папки
   (`Add file → Upload files`, перетащить содержимое папки целиком).
   Папка `.github` скрытая: если её не видно, включите показ скрытых файлов.
3. **Settings → Pages → Source:** выберите **GitHub Actions**.
4. **Settings → Actions → General → Workflow permissions:**
   выберите **Read and write permissions** и сохраните.
5. **Actions → Update offers → Run workflow.** Через 3–5 минут сайт появится
   по адресу `https://<ваш-логин>.github.io/berlin-angebote/`.

## Магазин EDEKA

Сайт отслеживает EDEKA Riebe (edeka.de/maerkte/408937). Чтобы взять другой
магазин EDEKA, найдите его на edeka.de, откройте его страницу акций и
вставьте её адрес в поле `url` в `scraper/config.py`.

## Если магазин не собрался

На сайте появится плашка «свежие акции загрузить не удалось», а прошлые
акции этого магазина останутся. Чтобы разобраться:

- откройте последний запуск во вкладке **Actions** и скачайте архив **debug**
  внизу страницы;
- в нём для каждого магазина есть `screenshot.png` (что увидел браузер),
  `page.html` и `summary.json` (сколько товаров нашлось и откуда).

Частая причина: сайт магазина не пускает запросы с серверов GitHub. Тогда
сборщик можно запускать у себя на компьютере:

```
pip install -r requirements.txt
python -m playwright install chromium
python scraper/scrape.py
```

и загружать получившийся `site/offers.json` в репозиторий.

## Как поправить группы

Группы задаются ключевыми словами в `scraper/categories.py`. Если, например,
«Kaffeesahne» попала в «Кофе и чай», а вы хотите видеть её в молочном,
добавьте `r"kaffeesahne"` в список `dairy` и поднимите группу `dairy`
выше `coffee_tea`.
